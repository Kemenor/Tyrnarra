How to use

  • Draw: click-drag on empty map (makes a new area).
  • L / T / plus shapes: select an area, then Shift+draw (or its ＋ button) to add another rectangle to it. The pieces together are one clickable area.
  • Move: drag a piece. Resize: drag its handles.
  • Select: click a piece, or an area's number in the list.
  • Reorder: drag an area's number in the list.
  • Nudge: arrow keys move the active piece; Shift+arrows resize it.
  • Delete: Delete/Backspace removes the active piece; the ✕ removes the whole area.
  • Give each area a label + description, then Copy / Download the JSON for me.
  • Auto-saves to this browser as you work; reloading the page restores your areas (and the map, if it fit storage). Clear all wipes it.
