How to use

  • Draw: click-drag on empty map.
  • Move: drag a box. Resize: drag its handles.
  • Select: click a box or its number in the list.
  • Reorder: drag a box's number in the list (the numbers renumber to match).
  • Nudge: arrow keys move; Shift+arrows resize.
  • Delete: Delete/Backspace, or the ✕ in the list.
  • Give each box a label and a description (the feel / contents), then Copy or Download the JSON and hand it to me.
