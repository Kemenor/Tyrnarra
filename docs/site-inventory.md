## `/player-campaigns/`: Player campaign companions (published)

A **player-facing** campaign layer (the play layer), published with its **own self-contained menu** (`pc-nav.*`), separate from the world/setting sidebar. Each menu crosses to the other via a foot button (the setting nav's *Player Campaigns →*, the campaign nav's *← The World · Setting*). Distinct from the GM `/gm-notes/` tree below: this is what players read; that is behind the screen. It uses its own themeable chrome rather than Style A/B. Architecture: [`campaign-layer.md`](campaign-layer.md).

- **`player-campaigns/assets/`**: shared player-campaign chrome — `campaign.css` (a GM-rooted ink-slate look, **fully CSS-variable-driven** so each campaign re-skins the whole section from its own `theme.css`), `campaign.js` (delegated interactions: quest-board expand, the clickable **room map** via `window.CAMPAIGN_ROOMS`, and `.reveal` rumour toggles), and `pc-nav.css` / `pc-nav.js` (the layer's own off-canvas menu, mirroring the GM `gm-nav.*` pattern; single source of truth for the campaigns menu is the `TREE` in `pc-nav.js`). Pages load `pc-nav.*` instead of the world `/setting/assets/site-nav.*`; the page body is themed by the campaign's `theme.css`.
- **`player-campaigns/index.html`**: section landing (default theme), `data-page="campaigns"` — what the layer is + a card per campaign. Named `index.html` so `/player-campaigns/` opens it directly.

Re-skinned by `theme.css` (mood: lamplit river-guild at night — blue-slate ground with a teal Smáa-underglow, brass compass-rose accent, harbour-blue secondary, Uncial Antiqua titles). One file = the campaign's whole look.
  - **`furrious-five.html`** *(`ff-hub`)*: campaign hub — premise + cards to the three locations.
  - **`wayward-compass.html`** *(`ff-wayward-compass`)*: the centrepiece. ## `/gm-notes/`: GM campaign layer (NOT published to players)

GM / table material, **unlinked from the player sidebar**; not part of the published-site rosters above. Architecture: [`campaign-layer.md`](campaign-layer.md).

- **`published/gm-notes/index.html`**: Base landing for the GM layer (what it is + a card per campaign + a Tools card).
- **`published/gm-notes/assets/`**: Shared GM chrome — `gm.css` (behind-the-screen styling, incl. the clickable-battlemap `.map-hot` styles), `gm.js` (delegated interactions: tabs, `⚿` secrets, NPC cards, floorplan room-cells via `window.GM_ROOMS`, battlemap hotspots via `window.GM_MAP_AREAS`), `gm-nav.css` / `gm-nav.js` (GM left-sidebar drawer, its own source-of-truth tree).
- **`published/gm-notes/tools/map-area-editor.html`**: GM tool — load a battlemap, draw / move / resize / delete + label / describe clickable areas (union-of-rectangles for L/T/plus shapes), reorder, export JSON for a quest's map tab; imports back-compatibly.
- **`tools/encounterBuilder/`** *(extracted to repo-root `/tools/`, not served)*: PF2e encounter + loot builders (`encounter.py` / `loot.py`) over a local SQLite snapshot of the Foundry pf2e data; the `pf2e-encounter` / `pf2e-loot` skills drive these. DBs are gitignored/rebuildable via `rebuild.py`.
- **`tools/foundryExport/`** *(extracted to repo-root `/tools/`, not served)*: `foundry_macro.py` — turns a quest spec into a paste-and-run Foundry VTT import macro: builds a foldered actor set (Monsters/NPCs/Loot subfolders) imported from the world's own compendiums by name (no Paizo data shipped), supports **embedded custom statblocks** for bespoke monsters, creates loot-actor chests with items + coins, and optionally **pre-places tokens** on the active scene and assigns **portrait + circle-masked token art** to NPCs. Subcommands: `build`, `spec` (assemble from encounter/loot `--json`), `assign-images` (apply portraits to an already-imported quest). `bake_token.py` bakes faction-framed tokens and `upload_forge.py` pushes art to The Forge Assets Library via its API. (Image generation now lives in `tools/imageGen/`; API keys in gitignored `tools/keys/`.) Phase 7 of `quest-workflow`; verified live on Foundry VTT 14.363 / pf2e 8.2.0.
- **`tools/imageGen/`** *(extracted to repo-root `/tools/`, not served)*: NPC art generation on the local GPU (ComfyUI + FLUX.2, no API key, Claude-operated via the `npc-art` skill). `npc_art.py` renders a consistent multi-shot set per character from a Claude-authored `*.set.json` (variations → chosen anchor → reference-conditioned portrait/scene, `mode:text` override for clean crops), plus token-frame ring art on demand. Generated art is committed. (The fal.ai/Midjourney cloud tiers were retired June 2026; git history has them.)
- **`tools/keys/`** *(extracted to repo-root `/tools/`, not served)*: gitignored API key files (`forge_key.txt`), copied from Proton Drive on a fresh clone.
- **`tools/map-library/`** *(extracted to repo-root `/tools/`, not served)*: shared reusable map catalogues. `magirail-stock.md` (the Tom Cartos modular train-car library: per-car descriptions, role tags, consist recipes), `stitch.py` (assemble a consist → composite image + merged areas JSON, with a `token:variant` selector for per-car detail files), `areas/` (committed per-car interior area files). Source art is local-only in `_full/`, synced between machines via Proton Drive (see `map-library/README.md`).
- **`tools/token-frames/`** *(extracted to repo-root `/tools/`, not served)*: shared Foundry token-frame library — `faction-frames.json` plus the framed ring art consumed by `foundryExport/bake_token.py`; new faction frames are rendered on demand via the `npc-art` skill.
- **`published/gm-notes/gm-reference/`**: GM quick-reference docs. `dc-cheatsheet.md` — the PF2e DC tables (level-based, simple, difficulty/rarity adjustments), the four-degrees rule, the skill list, and the principle that a DC anchors on the *challenge* not the party; worked examples from *The Narrows Job*.
- **`published/gm-notes/furrious-five/`** — the *Furrious Five* campaign (starting town Millhaven):

Five tabs (The Block, Playing Him, The Web, Threads, Portraits): stat block + skills/DCs, roleplay notes + read-aloud, his relationship web (bridge bloc, Watch, the old crew, Rika Tikur past), four live threads, and the Midjourney portrait set.
